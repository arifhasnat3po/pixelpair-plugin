# Changelog

## 0.9.0 — Initial public release

- Meta Pixel and Conversions API, Google Analytics, Tag Manager, and TikTok Pixel/Events API connections.
- Automatic events and a custom event builder with per-platform mappings and payload previews.
- WooCommerce classic/Blocks and HPOS support, Easy Digital Downloads tracking, and persisted paid-purchase identities.
- Consent integrations, role/IP/bot exclusions, encrypted credentials, bounded server retries and optional redacted logs.
- A shared admin interface with connection status, a skippable setup wizard, unsaved-change protection and immediate toggles with Undo.
- Privileged Head & Footer scripts, configuration import/export without secrets, and authenticated MCP configuration tools.
- Illustrated user guides, public source and a built installation ZIP.

Live advertising-account receipt, commercial subscription extensions and production host/cache configurations need site-specific verification. Refund delivery and Google Analytics server delivery are not included. This is a GitHub release, not a WordPress.org directory approval.
