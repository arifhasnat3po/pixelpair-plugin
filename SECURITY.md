# Security policy

Report a suspected vulnerability through [GitHub's private vulnerability reporting form](https://github.com/arifhasnat3po/pixelpair-plugin/security/advisories/new). Do not open a public issue with exploit details, credentials or customer information.

Include the affected version, relevant WordPress/PHP versions, reproduction steps, impact and a minimal example using disposable data. Remove tokens and personal information from screenshots and logs. Test only on systems you own or are authorized to assess.

Security fixes target the latest release. Older releases may need to be upgraded; no response-time or maintenance-duration guarantee is implied.

If a live token or Application Password has been exposed, revoke or replace it at its issuing service. Deleting a public message does not revoke the credential.
