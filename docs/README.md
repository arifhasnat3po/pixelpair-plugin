# PixelPair documentation

Start with [Getting started](guides/getting-started.md) to install the built plugin and connect Meta. Every guide uses the labels shown in WordPress.

## Guides

| Guide                                                  | What you can do                                                            |
| ------------------------------------------------------ | -------------------------------------------------------------------------- |
| [Getting started](guides/getting-started.md)           | Install, run setup and verify browser events                               |
| [Connections](guides/connections.md)                   | Configure Meta, Google Analytics, Tag Manager and TikTok                   |
| [Events](guides/events.md)                             | Control automatic events and create a custom button event                  |
| [Stores](guides/stores.md)                             | Track WooCommerce and EDD activity                                         |
| [Privacy and settings](guides/privacy-and-settings.md) | Choose consent behavior, exclusions and cache mode; transfer configuration |
| [Activity and scripts](guides/activity-and-scripts.md) | Inspect server responses and configure privileged scripts                  |
| [AI access](guides/ai-access.md)                       | Connect an authenticated external AI client                                |
| [Troubleshooting](guides/troubleshooting.md)           | Resolve installation and tracking problems                                 |
| [Screenshot gallery](screenshots.md)                   | Browse the complete admin interface                                        |

Screenshots show demonstration data. A shown error or result is an example; it does not describe your account. PixelPair follows the WordPress admin color scheme, so some screenshots use the Coffee accent and others use Light.
